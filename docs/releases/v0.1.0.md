# Atlas v0.1.0

Atlas is a terminal session manager for coding agents. It opens Codex,
Claude, Muse, or a shell in the right directory and uses tmux to make those
sessions discoverable and manageable from any terminal on the same machine.
The TUI can find, preview, resume, attach to, and safely end sessions.

## Requirements

- Linux on x86_64 or arm64. The x86_64 binary uses Bun's baseline target for
  broader CPU compatibility.
- Bun is bundled into the standalone binaries and is not required at runtime.
- tmux is required for persistent cross-terminal session management. Without
  tmux, Atlas can still launch a runtime directly but cannot manage it from
  another terminal.
- Codex, Claude, or Muse must already be installed and available on `PATH` to
  use that runtime. Shell sessions use `$SHELL`, falling back to `/bin/sh`.

## Install on Linux x86_64

Downloads stay in a temporary directory. Extraction and installation run only
after both downloads and checksum verification succeed.

```sh
(
  atlas_download_dir=$(mktemp -d) &&
  cd "$atlas_download_dir" &&
  curl -fLO https://github.com/DEVxEAZY/atlas-cli/releases/download/v0.1.0/atlas-linux-x64.tar.gz &&
  curl -fLO https://github.com/DEVxEAZY/atlas-cli/releases/download/v0.1.0/atlas-linux-x64.tar.gz.sha256 &&
  sha256sum --check atlas-linux-x64.tar.gz.sha256 &&
  tar -xzf atlas-linux-x64.tar.gz &&
  mkdir -p "$HOME/.local/bin" &&
  install -m 0755 atlas-linux-x64 "$HOME/.local/bin/atlas"
)
```

## Install on Linux arm64

```sh
(
  atlas_download_dir=$(mktemp -d) &&
  cd "$atlas_download_dir" &&
  curl -fLO https://github.com/DEVxEAZY/atlas-cli/releases/download/v0.1.0/atlas-linux-arm64.tar.gz &&
  curl -fLO https://github.com/DEVxEAZY/atlas-cli/releases/download/v0.1.0/atlas-linux-arm64.tar.gz.sha256 &&
  sha256sum --check atlas-linux-arm64.tar.gz.sha256 &&
  tar -xzf atlas-linux-arm64.tar.gz &&
  mkdir -p "$HOME/.local/bin" &&
  install -m 0755 atlas-linux-arm64 "$HOME/.local/bin/atlas"
)
```

If `~/.local/bin` is not already on `PATH`, add it in your shell startup
file. Verify the installation directly:

```sh
"$HOME/.local/bin/atlas" --help
```

Then run `atlas` to open the TUI, or inspect a launch without starting it:

```sh
atlas --dir /path/to/project --runtime shell --print
```

## Known limitations

- This release provides Linux binaries only; macOS and Windows are not yet
  packaged.
- The TUI is in Brazilian Portuguese.
- Atlas manages the machine where it runs. It is not an SSH client and does
  not synchronize sessions between machines.
- Native conversation discovery follows the local storage formats used by
  Codex, Claude, and Muse, which may change in future runtime releases.

## Next
