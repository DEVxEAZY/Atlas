# Atlas v0.3.0

Atlas finds, previews, and re-enters your Codex, Claude, Muse, and shell
sessions from one terminal hub, backed by tmux. This release covers 0.2.0
(npm) and 0.3.0.

## Highlights

- **`atlas .`** takes you straight back to a directory's session. Atlas
  attaches to the live tmux session, opens the management view of an agent
  already running there, starts the runtime you last used there, or asks
  which runtime to start. It never opens a duplicate.
- **Double `T` in the Hub** moves a session or conversation into tmux in the
  background. A session running elsewhere is stopped and resumed in a
  detached tmux session; an idle conversation just opens there.
- **Conversations are found more reliably.** Claude conversations whose
  first prompt sits past 64 KB now show their directory and preview, so
  resuming them starts in the right project. Codex conversations with an
  oversized `session_meta` line no longer disappear. Previews skip text the
  harness injected (command caveats, command echoes).
- **Published on npm** as `@devxeazy/atlas-cli`.
- **Smoother on more terminals.** The TUI draws on the alternate screen, and
  long rows truncate instead of wrapping, so frames never outgrow the window
  and the mouse wheel no longer scrolls through stale frames.
- A small ASCII boat sails the footer as an endless loading animation
  (`ATLAS_NO_BOAT=1` hides it).
- Adds a [pt-BR UI glossary](https://github.com/DEVxEAZY/atlas-cli/blob/main/docs/ui-glossary.md) for English speakers.

## Install

With [Bun](https://bun.sh) on `PATH`:

```sh
bun add -g @devxeazy/atlas-cli
```

Or download a standalone binary (Bun included) from the assets below.
Verify it with its `.sha256` file:

```sh
atlas_asset=atlas-linux-x64   # or atlas-linux-arm64
curl -fLO "https://github.com/DEVxEAZY/atlas-cli/releases/download/v0.3.0/$atlas_asset.tar.gz"
curl -fLO "https://github.com/DEVxEAZY/atlas-cli/releases/download/v0.3.0/$atlas_asset.tar.gz.sha256"
sha256sum --check "$atlas_asset.tar.gz.sha256" && tar -xzf "$atlas_asset.tar.gz"
mkdir -p "$HOME/.local/bin" && install -m 0755 "$atlas_asset" "$HOME/.local/bin/atlas"
export PATH="$HOME/.local/bin:$PATH"   # add to your shell startup file if needed
```

On WSL, install inside the Linux distribution. Running the Windows `npm`
from WSL fails with `EBADPLATFORM`.

## Requirements

Linux on x86_64 or arm64, including WSL. tmux is needed for sessions that
persist across terminals. Codex, Claude, or Muse must be installed on `PATH`
to use that runtime.

See the [changelog](https://github.com/DEVxEAZY/atlas-cli/blob/main/CHANGELOG.md) for every change.
